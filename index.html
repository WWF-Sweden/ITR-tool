WWF ITR Tool: Temperature Scoring & Portfolio Coverage

Understand what drives your portfolio’s temperature score and use the results to inform engagement and portfolio analysis. The WWF ITR Tool implements the CDP-WWF Temperature Scoring Methodology v1.5. It calculates company and portfolio temperature scores from climate targets, and portfolio coverage by SBTi-validated near-term targets.

Docker runs the same Streamlit app locally. You can also run Streamlit directly with Python. For confidential portfolios, choose a local app or notebook environment rather than the public cloud demo or Colab.

One toolkit, shared calculations

WWF ITR Tool is the toolkit as a whole. wwf-itr, developed in ITR-tool, is the Python scoring engine (imported as ITR). WWF-ITR-APP provides the Streamlit interface to that engine. The scoring notebooks use the engine too; the simplified portfolio coverage notebook is a standalone pandas example.

Use Introduction to temperature scoring and portfolio coverage methods for an explanation of the method and outputs, Data Requirements to prepare files, and Data Legends for field definitions. The tool accepts user-supplied company and portfolio data; example files are demonstrations, not an investment data service. The API Reference describes the Python interface.

Questions or problems? See Troubleshooting and Project Links. Contributions to code, examples and documentation are welcome; see Contributing. Results describe target-based alignment assumptions and do not guarantee future emissions or official target validation.
