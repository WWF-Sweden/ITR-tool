Getting Started Using Python

Use the wwf-itr package to integrate temperature scoring into your own analysis. The Python import name is ITR. For a graphical interface, use Getting Started with the App; for guided runnable examples, use Getting Started with Notebooks.

Installation

Use Python 3.10 or later. Python 3.11 is a practical starting point. Create and activate an environment, for example on macOS/Linux:

python3 -m venv .venv
source .venv/bin/activate

On Windows PowerShell:

py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

Install the published package:

python -m pip install wwf-itr

For source development, clone https://github.com/WWF-Sweden/ITR-tool.git and install with python -m pip install -e . from the repository root. See Contributing for development and documentation dependencies.

First temperature score calculation

Save the following as first_analysis.py in your working folder and run python first_analysis.py. The script downloads two public sample files only when they are absent, calculates all scopes for the mid-term timeframe, prints portfolio scores, and writes company results to CSV. The example uses the same fictional 360-company dataset as the notebooks; see Getting Started with Notebooks for direct downloads. Sample data is illustrative; scores can change with the calendar year because target timeframes are forward-looking.

"""First analysis with the public WWF ITR sample files."""
from pathlib import Path
from urllib.request import urlretrieve

import pandas as pd
import ITR
from ITR.data.excel import ExcelProvider
from ITR.interfaces import EScope, ETimeFrames
from ITR.portfolio_aggregation import PortfolioAggregationMethod
from ITR.temperature_score import TemperatureScore

data_dir = Path("data")
data_dir.mkdir(exist_ok=True)
base_url = "https://raw.githubusercontent.com/WWF-Sweden/ITR-tool/main/examples/data/"
for filename in ("data_provider_example_360.xlsx", "example_portfolio_360.csv"):
    path = data_dir / filename
    if not path.exists():
        urlretrieve(base_url + filename, path)

print(f"wwf-itr version: {ITR.__version__}")
provider = ExcelProvider(path=str(data_dir / "data_provider_example_360.xlsx"))
portfolio = pd.read_csv(
    data_dir / "example_portfolio_360.csv",
    dtype={"company_id": str, "company_isin": str, "company_lei": str},
)
companies = ITR.utils.dataframe_to_portfolio(portfolio)
scorer = TemperatureScore(
    time_frames=[ETimeFrames.MID],
    scopes=[EScope.S1, EScope.S2, EScope.S1S2, EScope.S3, EScope.S1S2S3],
    aggregation_method=PortfolioAggregationMethod.WATS,
)
company_scores = scorer.calculate(data_providers=[provider], portfolio=companies)
if scorer.invalid_targets:
    print("Skipped targets:")
    print(pd.DataFrame(scorer.invalid_targets).to_string(index=False))

portfolio_scores = scorer.aggregate_scores(company_scores)
for scope, result in portfolio_scores.model_dump()["mid"].items():
    if result is not None and result["all"] is not None:
        print(f"MID {scope}: {result['all']['score']:.2f} degrees C")
company_scores.to_csv("company_temperature_scores.csv", index=False)
print("Saved company_temperature_scores.csv")

company_scores has one row per calculated company/scope/timeframe combination, including temperature_score and underlying data. portfolio_scores contains the weighted results and contributions. Use portfolio_scores.model_dump() for a dictionary representation. Review skipped-target messages before relying on the outputs. See Functional Overview for weighting and default-score interpretation.

Replace the two input paths with your own files using Data Requirements. Include prerequisite scopes when calculating combined scopes; this example explicitly requests all five. For grouped results, pass a list such as grouping=["sector"] to TemperatureScore. For more analysis and export examples, use Getting Started with Notebooks.

Portfolio coverage

SBTi portfolio coverage can be calculated from a portfolio file without calculating temperature scores. The following example uses WATS and the sample portfolio downloaded above:

import pandas as pd
from ITR.portfolio_aggregation import PortfolioAggregationMethod
from ITR.portfolio_coverage_tvp import PortfolioCoverageTVP

portfolio = pd.read_csv(
    "data/example_portfolio_360.csv",
    dtype={"company_id": str, "company_isin": str, "company_lei": str},
)
coverage_calculator = PortfolioCoverageTVP()
coverage = coverage_calculator.get_portfolio_coverage(
    portfolio.copy(), PortfolioAggregationMethod.WATS
)
print(f"Portfolio coverage: {coverage:.2f}%")

The result is already a percentage from 0 to 100. To use a specific CTA snapshot, construct PortfolioCoverageTVP(cta_file_path="data/my-cta.xlsx"). See SBTi status for status matching, caches and fallback behaviour. Keep input snapshots and record ITR.__version__ with the analysis.

If you only need investment-weighted coverage and do not want to install the scoring package, use the standalone coverage notebook in Getting Started with Notebooks. It uses pandas directly and has its own CTA loading rules.
